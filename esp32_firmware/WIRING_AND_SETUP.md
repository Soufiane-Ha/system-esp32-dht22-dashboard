# دليل توصيل عتاد ESP32 مع حساس DHT22 وبرمجته

## 1. مخطط التوصيل (Wiring Diagram)

حساس DHT22 يحتوي عادةً على 4 أرجل (أو 3 أرجل إذا كان على لوحة موديول جاهزة):

```
       ┌───────────────┐
       │     DHT22     │
       │   AM2302      │
       │  [+] [D] [-]  │
       └───┬───┬───┬───┘
           │   │   │
           │   │   └───────────────── ESP32 GND
           │   │
           │   └──────[ Resistor ]─── ESP32 GPIO 4
           │          (10k Pull-up)
           └───────────────────────── ESP32 3V3 (أو VIN 5V)
```

### جدول التوصيل:

| رجل حساس DHT22 | وظيفة الرجل | منفذ ESP32 المقابل | ملاحظات |
|----------------|-------------|-------------------|---------|
| **Pin 1 (VCC)** | التغذية الكهربائية | **3V3** (أو **5V/VIN**) | يفضل 3.3V للتوافق مع مستويات جهد ESP32 |
| **Pin 2 (DATA)**| خط البيانات | **GPIO 4** | يحتاج مقاومة شد 4.7kΩ أو 10kΩ إلى 3V3 |
| **Pin 3 (NC)**  | غير مستخدم | غير متصل | (فقط في الحساس ذو 4 أرجل) |
| **Pin 4 (GND)** | الأرضي | **GND** | توصيل بالأرضي المشترك |

> **ملاحظة:** إذا كنت تستخدم موديول DHT22 الجاهز الملحوم على شريحة زرقاء أو حمراء ذات 3 دبابيس (VCC, DATA, GND)، فإن مقاومة الشد (Pull-up resistor) تكون مدمجة بالفعل ولا داعي لإضافة أي مقاومة خارجية!

## 2. خطوات البرمجة في برنامج Arduino IDE

1. **تثبيت حزمة لوحة ESP32:**
   - افتح **Arduino IDE** -> **File** -> **Preferences**.
   - في حقل **Additional boards manager URLs** أضف الرابط:
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - اذهب إلى **Tools** -> **Board** -> **Boards Manager**، وابحث عن `esp32` وقم بتثبيته (بواسطة Espressif Systems).

2. **تثبيت المكتبات المطلوبة:**
   - اذهب إلى **Sketch** -> **Include Library** -> **Manage Libraries...**
   - ابحث عن:
     - `DHT sensor library` (من Adafruit) واضغط **Install All**.
     - `PubSubClient` (من Nick O'Leary) واضغط **Install**.

3. **تعديل الإعدادات في الكود (`esp32_dht22_mqtt.ino`):**
   - ضع اسم شبكة الواي فاي وكلمة المرور الخاصة بك:
     ```cpp
     const char* ssid = "اسم_الواي_فاي_عندك";
     const char* password = "كلمة_المرور";
     ```
   - إذا كان الحاسوب والـ ESP32 متصلين بنفس شبكة الراوتر وتريد استخدام البروكر المحلي:
     ضع عنوان IP الخاص بحاسوبك (مثلاً: `"192.168.1.50"`).
   - إذا كنت تفضل البروكر السحابي بدون الحاجة لمعرفة IP الحاسوب:
     اتركها `"broker.emqx.io"`.

4. **رفع الكود (Upload):**
   - اختر اللوحة المناسبة من **Tools** -> **Board** -> **ESP32 Dev Module**.
   - اختر منفذ الـ COM الخاص بك من **Tools** -> **Port**.
   - اضغط على زر **Upload** (السهم الأيمن).
   - افتح **Serial Monitor** واضبط السرعة على **115200 baud** لمشاهدة البيانات الحية أثناء الإرسال.
